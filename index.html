Semua yang kamu butuhkan, dalam satu jendela

Setiap panel berdiri sebagai modulnya sendiri di dalam src/, jadi mudah dipelajari dan dikembangkan.

Editor inti

Nomor baris, find/replace mengambang, indentasi Tab/Shift+Tab, dan indikator baris aktif.

Penyorotan sintaks

KSyntaxHighlighting memilih grammar otomatis dari ekstensi — lebih dari 400 bahasa, tema gelap/terang.

Autocomplete

Saran kata per tipe berkas: keyword bahasa, tag, atribut, properti CSS, kunci JSON, hingga anggota objek.

Minimap

Kolom ringkasan berwarna token di kanan editor, lengkap dengan indikator viewport yang bisa diklik.

Explorer & berkas

Tree view dengan drag & drop, buat / ganti nama / hapus ke Recycle Bin, tempel gambar, dan filter.

Pencarian

Cari di dalam berkas maupun seluruh proyek, hasilnya bisa diklik untuk langsung membuka barisnya.

Source Control

Status perubahan, commit, push dan pull langsung dari sidebar — tanpa keluar dari editor.

API Client

Klien REST bawaan: susun permintaan, tambah header, kirim, lalu periksa respons dalam satu tab.

Skill / Plan

Kelola AGENTS.md, daftar plan per proyek, dan riwayat penyimpanan berkas — semuanya dari satu panel.

Database

Telusuri skema, lihat tabel dan kolom, lalu buka kanvas relasi antar tabel.

Terminal

Dua terminal: kolom kanan untuk agen AI CLI, panel bawah untuk menjalankan build dan uji.

Split editor

Buka sampai empat panel dalam satu jendela, termasuk tata letak dua kolom, grid, dan campuran.

Kenapa NxCode IDE

Ringan, native,
dan langsung produktif.

NxCode IDE dirancang sebagai satu jendela untuk seluruh alur kerja: buka proyek, tulis kode, jalankan terminal, kelola versi, uji API, dan telusuri database — tanpa berpindah-pindah aplikasi. Semuanya berjalan sebagai aplikasi desktop native yang cepat dan hemat memori.

  • Buka dalam sekejap — tanpa peramban, tanpa runtime berat.
  • Penyorotan sintaks 400+ bahasa siap dipakai.
  • Tema gelap/terang dan pengaturan yang tersimpan otomatis.

Jalankan NxCode IDE di komputermu

Pilih sistem operasimu, unduh paketnya, lalu langsung jalankan — tanpa perlu menyiapkan tool build apa pun.

Kebutuhan

  • Windows 10 (1809+) atau Windows 11, 64-bit.
  • NxCode IDE — cukup unduh dan jalankan installer.
  • macOS 12+ (Intel atau Apple Silicon), 64-bit.
  • Belum tersedia — paket .dmg untuk macOS sedang disiapkan.
  • Distribusi Linux 64-bit dengan Qt 6 (mis. Ubuntu 22.04+).
  • Ekstrak tar.gz lalu jalankan ./editor.
